# 产品路线图与演进规划 (Roadmap)

本文档呈现「文章摆渡」的长期愿景、核心演进阶段与功能储备池。

## 🎯 发展路线图阶段规划

### 第一阶段：单线基准打磨与极致稳定（v0.5.0 ~ v0.6.1，已完成 ✅）
- [x] 重构双 Tab 扁平仪表盘与自适应深色模式
- [x] CSDN 在线呼吸光晕状态胶囊与健康检测预警
- [x] 无水印高清原图直链提取与通用容器清洗
- [x] 同步前排版预演 (Dry-run) 零副作用分析
- [x] 400 删稿自愈降级新建与双身份草稿幂等
- [x] Chrome 原生系统通知长耗时触发与防抖拦截
- [x] 存储瘦身防爆仓与结构化脱敏诊断

### 第二阶段：多平台矩阵扩张（v1.0.0 里程碑，已正式通航 🎉）
- [x] **一键同步多平台架构**：
  - 掘金 Markdown 编辑器、创作者中心与个人文章列表统一挂载「同步多平台」按钮；
  - 弹窗自由勾选目标平台（CSDN、微信公众号），独立并发任务、进度通知与失败重试；
- [x] **微信公众号草稿箱全链路通航**：
  - 新增微信专用 Markdown 编译器，内联关键排版样式，实现代码块横向平滑滚动防折行；
  - 正文图片无损转存至微信素材库；
  - 源封面智能适配：自动裁剪生成 16:9、1:1、3:4 三套官方标准尺寸并绑定草稿；
  - 微信网页登录态端侧检测，0 Cookie 权限申请，账号严格隔离；
- [x] **CSDN 与微信双通道独立调度**：
  - 两大平台独立草稿映射，失败重试互不影响。

### 第三阶段：全域矩阵与创作者数据资产（v1.1.0 ~ v1.2.0，进行中 🚧）
- [ ] **知乎专栏草稿箱摆渡**：
  - 探索端侧知乎创作者中心草稿写入通道；
- [ ] **博客园 (Cnblogs) 摆渡适配**：
  - 接入 MetaWeblog 规范或 Markdown 编辑器端侧转存；
- [ ] **【数据主权】掘金个人文章一键全量本地归档**：
  - 一键将作者本人的全部掘金文章、分类、标签连同高清图床原图，打包下载为离线 ZIP 归档；
- [ ] **导出为标准 Hugo / Hexo / Astro 静态博客格式**：
  - 自动生成 YAML Frontmatter 头信息（含 `title`、`date`、`tags`、`categories`），一键无缝转换为独立博客。

## 🛡️ 架构演进红线原则

无论产品如何迭代扩张，以下红线永不妥协：
1. **坚决不替用户公开发布**：确认权永远在目标平台草稿箱；
2. **坚决不引入中心化第三方代理服务器**：计算全在浏览器端侧沙箱内完成；
3. **坚决不向用户索要平台登录密码或 Cookie**。
