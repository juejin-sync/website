⚡ 如何启用永久数据持久化 (Upstash Redis)

为文章摆渡配置免费的云端键值存储，永久跨天记录官网的每一次访问与下载，每月免费 10,000 次请求：

  1. 打开 Upstash 控制台（支持 GitHub 快速免密登录）；
  2. 点击 Create Database，选择 Regional / Free 免费套餐；
  3. 在数据库详情页中，复制 REST API 下的两个环境变量：
UPSTASH_REDIS_REST_URL="https://...upstash.io"
UPSTASH_REDIS_REST_TOKEN="AZ...="

将这两个变量填入 Vercel 项目的 Project Settings → Environment Variables 中，重新部署后即可自动无缝激活云端持久化！
